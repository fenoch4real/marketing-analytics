# Marketing Analytics

This repository contains coursework and project analyses applying data science methods to marketing questions. The work is organized as Jupyter notebooks with exported HTML reports and supporting data files.

## Analyses

- **Campaign analytics** — explores digital retail media performance and predictive modeling.
- **Product positioning and brand strategy** — analyzes brand strategy and product positioning.
- **Market segmentation** — examines survey data to identify market segments.
- **Brand perception mapping** — presents a brand perception analysis.
- **Choice-based conjoint analysis** — analyzes consumer choice preferences.
- **Competitive analysis** — explores the competitive landscape.

## Repository contents

| Files | Description |
| --- | --- |
| `*.ipynb` | Editable analysis notebooks |
| `*.html` | Rendered reports for selected analyses |
| `*.xlsx`, `*.xls` | Supporting campaign and market-segmentation data |
| `*.pdf` | Market-segmentation presentation and report |

Several notebooks refer to source datasets that are not present in the repository or whose filenames differ from the included files. As a result, rerunning a notebook may require locating the original data and updating its input path.

## Opening the analyses

Open a notebook in Jupyter Notebook or JupyterLab to inspect the code and results. The HTML reports can be opened directly in a web browser without a notebook environment.
